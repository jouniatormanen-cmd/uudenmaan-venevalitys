# Uudenmaan Venevälitys – mobiililähtöinen sivupohja

## Tiedostot
- `index.html` – etusivun sisältö
- `style.css` – responsiivinen ulkoasu ja mobiilivalikko
- `script.js` – valikon toiminta ja lomakkeen esikatselu
- `assets/logo.svg` – alustava purje- ja aaltotunnus

## GitHub Pages
1. Avaa repositoryn **Settings → Pages**.
2. Valitse **Deploy from a branch**, branchiksi `main` ja kansioksi `/(root)`.
3. Tallenna. Julkinen sivu tulee osoitteeseen https://jouniatormanen-cmd.github.io/uudenmaan-venevalitys/

## Ennen julkaisua
- Vaihda etusivun väliaikainen taustakuva vene-/saaristokuvaan, jonka käyttöoikeus on kunnossa.
- Liitä yhteydenottolomakkeeseen Formspree, Web3Forms tai muu palvelu. Nykyinen lomake ei lähetä tietoja.
- Lisää oikeat yhteystiedot ja tietosuojaseloste.
- Tarkista välitystoiminnan ehdot, vakuutukset ja hinnoittelun ALV-käsittely ennen julkaisua.
- Vahvista palvelun nimen ja verkkotunnuksen käyttökelpoisuus.

Hinnoittelutekstit ovat suunnitteluluonnoksia, eivät sitova tarjous.
